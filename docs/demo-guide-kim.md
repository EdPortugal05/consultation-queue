# Consultation Queue: Demo Walkthrough

A quick guide to presenting the Consultation Queue app from start to finish.

## Before you start
1. Install the dependencies with `npm install`.
2. Start the app with `npm run dev` and open the local link shown in the terminal.
3. Open that same link in a second tab of the same browser. One tab is for the student and the other is for the teacher.

## Part 1: Student (Tab 1)
1. Tap "I'm a student" and enter your name.
2. Choose a subject and a concern type.
3. Write your concern, then tap "Join the queue".
4. A queue number appears to confirm you're in line.

## Part 2: Teacher (Tab 2)
1. Tap "I'm a teacher" and choose Jeremy Zion L. Jamer.
2. Enter the PIN 1234.
3. Open the new concern from the list.
4. Tap "Start consultation" and write a private comment for the student.

## Part 3: Private conversation
1. Go back to Tab 1 and open the concern under "My concerns".
2. Reply to the teacher in the same private thread.

## Part 4: Teacher tools
1. Star the concern to mark it as a priority.
2. Set a consultation slot.
3. Tap "Mark resolved" when the concern is done.

## Reset the demo
- To start over, tap "Reset demo data" on the first page.
