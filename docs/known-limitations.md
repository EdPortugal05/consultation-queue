# Known Limitations

What the current version of Consultation Queue does not do yet.

- Data is saved in the browser only. A student on one device cannot see a teacher on another device. Use two tabs of the same browser to demo.
- Teacher PINs are stored in the front-end code, so sign-in is for demo use only and is not real security.
- Students do not have accounts. They find their concerns by typing the same name they used.
- There are no email or phone notifications.
- The "No-show" and "Open or close the queue" features are not built.
- A shared server (Express API) is planned for the next sprint so data can sync across devices.
